# Презентація для партнерів (a leading clinical research center, a partner platform, Ruijin)

> Повний presentation-ready бриф: **`docs/partner_brief.md`** (англійською).
> Усі фігури регенеруються: `python3 scenarios/generate_all.py`.

Подаємо НЕ як готовий продукт, а як концепт + архітектуру + робочу симуляцію-доказ
+ чесну карту mock/real + чесні негативні результати + унікальний внесок України.

## 1. Проблема й позиція (1 слайд)
- Травма розриває канал мозок→попереку; мозок здоровий, намір зберігається.
- BSI вже довів принцип (a landmark peer-reviewed study, 2023). Відкритий фронтир — не
  «чи можна підняти людину», а **адаптивна оркестрація**: втома, дрейф, баланс,
  перемикання режимів у реальному часі.
- Наш шар лягає **поверх** реальної платформи стимуляції, а не дублює її.

## 2. Архітектура (1–2 слайди)
- 6 шарів + supervisory LLM поза realtime; safety з абсолютним вето.
- Хода — фазова (CPG), фізіологічно коректна.
- Діаграма з `docs/architecture.md`.

## 3. Робоча симуляція — доказ концепту (демо)
- **Sit-to-stand** — перехід сидячи→стоячи, утримання балансу.
- **Walk** — ритмічна хода із замкнутим контуром; ін'єкція збурення → видиме
  відновлення балансу.
- **Stairs** — зміна режиму наміру → вищий кліренс кроку.
- Кожне демо логує: намір → фази → активації → стим-команди (до/після safety) →
  сенсори. Панелі `outputs/*_summary.png`, анімації `outputs/*.gif`.

## 3b. Автономні функції — нарівні з ходьбою (1 слайд)
- Сечовий міхур/кишківник/еректильна — той самий EES-субстрат, контури S2–S4.
- Контраст: дисинергія (DSD) → високий тиск, неповне спорожнення, автономна
  дисрефлексія (загроза життю) проти координованої нейромодуляції.
- Демо `autonomic_demo.py`, графік `outputs/autonomic_bladder.png`.

## 4. Safety як фундамент довіри (1 слайд)
- 6 інваріантів; `test_safety.py` вичерпний.
- Жодна команда не обходить супервізор; e-stop; хард-ліміти-константи.
- Це мова, якою розмовляють із регулятором (IDE/CE/MDR).

## 5. Чесна карта mock vs real (1 слайд)
- Замокано: декодер, біофізика EES, стимулятор, тіло, регуляторика.
- Потрібно від партнера: recruitment-дані, платформа стимуляції, клінічна
  валідація, регуляторний шлях.

## 6. Унікальний внесок України / 1ТМО (ключовий гачок)
- Велика когорта SCI (зокрема військова) — датасет світового класу для навчання
  адаптивного шару. Це те, чого немає в a research center/a partner platform.
- Ігор — і пацієнт, і архітектор: рідкісна точка довіри для колаборації.

## 7. Запит (1 слайд)
- Спільний пілот: наш оркестраційний шар + їхня платформа + українська когорта.
- Конкретний наступний крок (технічний): бекенд MuJoCo, навчання адаптації на
  синтетичних → реальних (зі згодою) даних.
