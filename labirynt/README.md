# Лабіринт для двох

Подарунок для Саші й Софії. Одна сторінка, без фреймворків і збірки:
`index.html` + `style.css` + `app.js` + `content.js` + `lib/` + `assets/`.

## Як це працює для них

1. Вони відкривають **одне чисте посилання** — ані коду, ані статі в ньому немає.
2. Читають **заставку**: сім сторінок про них двох, про маму, про тата,
   про те, що таке дитина і що буде далі. Далі — по дотику.
3. Упираються в **замок**: «ключ поки що не у вас».
4. Дзвонять Ігорю. Він каже **пін-код**.
5. Код відчиняє двері — і тільки тоді починається лабіринт.
6. У центрі лабіринту — слово.

Заставку можна перечитати з екрана замка («перечитати спочатку»).
Після вдалого коду телефон це запам'ятовує: перезавантаження сторінки не
замикає двері назад.

## Пін-код

**Чинний код: `170305`.** Він ніде не записаний відкритим текстом — у
`content.js` лежить тільки повільний хеш (40 000 раундів SHA-256).
Стать теж не лежить відкрито: `secretToken` — це відбиток пари
«код + стать», і без коду з нього нічого не дістати.

### Змінити код або стать

1. Відкрий сайт із `#host` у кінці адреси — це панель ведучого.
2. Введи новий код (4–8 цифр) і натисни «Хлопчик» або «Дівчинка».
3. Скопіюй три рядки, що з'являться, і встав їх у `content.js`, у блок `lock`.
4. Закоміть і передеплой.

Кнопка «Пройти самому спочатку» на тій же панелі скидає «замок уже
відчинено» на цьому телефоні — щоб прогнати весь сценарій з нуля.

Для швидкої перевірки без коду є чорний хід `?s=south` (або `?s=north`):
пропускає заставку й замок. Параметр стирається з адреси одразу, у консоль
не потрапляє. **Паре це посилання не давати.**

## Деплой на Railway

Це окрема служба, вона нічого не знає про симулятор BSO в корені репо.

1. Railway → New Service → GitHub Repo → цей репозиторій.
2. Settings → **Root Directory: `labirynt`**.
3. Deploy. Далі нічого налаштовувати не треба: `Procfile`, `railway.json`
   і `requirements.txt` уже лежать усередині теки.
4. Settings → Networking → Generate Domain. Це і є посилання для пари.

Сервер — `server.py` на stdlib, без залежностей: віддає статику, ассети з
довгим кешем, код без кешу, будь-який невідомий шлях — назад на `index.html`.
У логи не пише ні шляхів, ні кодів.

Альтернатива — GitHub Pages: скопіювати вміст цієї теки в корінь окремого
приватного репо (Pages не публікує довільну підпапку, крім `/docs`).

## Інструкція Ігорю (5 рядків)

1. **Тексти заставки** — `content.js`, блок `prologue`: сім сторінок, у кожній масив рядків. `tone: 'a'` — кольори Саші, `'b'` — Софії.
2. **Запитання лабіринту** — там же, блок `questions`: по черзі Саша/Софія, у кожної відповіді є `trait` для «портрета батьків».
3. **Фото** — кинути `01.jpg, 02.jpg …` у `assets/photos/` і додати ті ж імена у список `photos.items`.
4. **Музика** — покласти `walk.mp3`, `reveal.mp3`, `memories.mp3` у `assets/audio/` (саме такі назви).
5. **Передеплой** — `git add -A && git commit -m "..." && git push`; Railway підхопить сам.

## Локальний запуск

```bash
cd labirynt
python3 server.py          # → http://localhost:8000
```

Відкривати через `file://` не можна — не завантажиться `content.js`.

## Що всередині

| Файл | За що відповідає |
|---|---|
| `content.js` | заставка, замок, запитання, варіанти фіналу, список фото, шляхи до аудіо |
| `app.js` | сценарій, лабіринт, звук, конфеті, Ken Burns, фінальна картка |
| `lib/sha256.js` | перевірка коду; без залежностей і без `crypto.subtle` |
| `style.css` | нічне небо / латунь / папір, переходи, `prefers-reduced-motion` |
| `server.py` | статика для Railway і для локального запуску |
| `IDEAS.md` | ідеї поза списком — навмисно не реалізовані |
| `QA.md` | що прогнано, що знайдено, що лишилось перевірити на живому iPhone |

Анімація: GSAP з CDN; якщо CDN недоступний, `app.js` перемикається на
власний rAF-фолбек — сценарій відпрацьовує однаково. Фішки рухаються
рівно вздовж кривої SVG (`getPointAtLength`), а не стрибками.
