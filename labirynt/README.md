# Лабіринт для двох

Подарунок для Саші й Софії. Одна сторінка, без фреймворків і збірки:
`index.html` + `style.css` + `app.js` + `content.js` + `assets/`.

## Три посилання

| Посилання | Що показує |
|---|---|
| `.../` | екран ведучого — **тільки для Ігоря** |
| `.../?s=north` | гра, у фіналі — **Хлопчик** |
| `.../?s=south` | гра, у фіналі — **Дівчинка** |

Параметр `?s=` стирається з адресного рядка одразу після завантаження —
на екрані пари його не видно, у консоль він не виводиться.
Найпростіше: відкрити `/` на своєму телефоні, натиснути потрібну кнопку,
скопіювати готове посилання і надіслати.

## Інструкція Ігорю (5 рядків)

1. **Тексти** — `content.js`: запитання, відповіді, риси, вердикт, reveal. Тільки текст у лапках, ключі не чіпати.
2. **Фото** — кинути `01.jpg, 02.jpg …` у `assets/photos/` і додати ті ж імена у список `photos.items` у `content.js`.
3. **Музика** — покласти `walk.mp3`, `reveal.mp3`, `memories.mp3` у `assets/audio/` (саме такі назви).
4. **Кольори й слова фіналу** — блок `variants` у `content.js` (`north` = хлопчик, `south` = дівчинка).
5. **Передеплой** — `git add -A && git commit -m "..." && git push`; GitHub Pages оновиться сам за хвилину.

## Локальний запуск

```bash
cd labirynt
python3 -m http.server 8000
# → http://localhost:8000/?s=north
```

Відкривати через `file://` не можна — не завантажиться `content.js`/аудіо.

## Деплой на GitHub Pages

Вміст цієї папки — корінь сайту. У приватному репо:
Settings → Pages → Source: `Deploy from a branch` → гілка + папка `/ (root)`.
Якщо папка `labirynt/` лежить усередині більшого репо — скопіювати її вміст
у корінь окремого репо (Pages не вміє публікувати підпапку, крім `/docs`).

## Що всередині

| Файл | За що відповідає |
|---|---|
| `content.js` | усі тексти, гравці, варіанти статі, список фото, шляхи до аудіо |
| `app.js` | сценарій, лабіринт, звук, конфеті, Ken Burns, фінальна картка |
| `style.css` | нічне небо / латунь / папір, переходи, `prefers-reduced-motion` |
| `IDEAS.md` | ідеї поза списком — навмисно не реалізовані |

Анімація: GSAP з CDN; якщо CDN недоступний, `app.js` перемикається на
власний rAF-цикл — сценарій відпрацьовує однаково. Фішки рухаються
рівно вздовж кривої SVG (`getPointAtLength`), а не стрибками.
