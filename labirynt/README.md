# Лабіринт для двох

Подарунок для Саші й Софії. Одна сторінка, без фреймворків і збірки:
`index.html` + `style.css` + `app.js` + `content.js` + `lib/` + `assets/`.

## Як це працює для них

1. Вони відкривають **одне чисте посилання** — ані коду, ані статі в ньому немає.
2. Перший екран питає, **хто відкрив** — Саша чи Софія. З цього дотику
   починається музика, і з цього ж вибору заставка починає звертання:
   першою йде сторінка того, хто тримає телефон. Другий не втрачає нічого —
   його сторінка йде наступною. Вибір памʼятається на цьому телефоні.
3. Читають **заставку**: сім сторінок про них двох, про маму, про тата,
   про те, що таке дитина і що буде далі. Далі — по дотику.
4. Упираються в **замок**: «ключ поки що не у вас».
5. Дзвонять Ігорю. Він каже **пін-код**.
6. Код відчиняє двері — і тільки тоді починається лабіринт.
7. У центрі лабіринту — слово.

Заставку можна перечитати з екрана замка («перечитати спочатку»).
Після вдалого коду телефон це запам'ятовує: перезавантаження сторінки не
замикає двері назад.

## Пін-код

**Чинний код: `170305`.** Він ніде не записаний відкритим текстом — у
`content.js` лежить тільки повільний хеш (40 000 раундів SHA-256).
Стать теж не лежить відкрито: `secretToken` — це відбиток пари
«код + стать», і без коду з нього нічого не дістати.

### Змінити код або стать

1. Відкрий сайт із `#host` у кінці адреси — це панель ведучого.
2. Введи новий код (4–8 цифр) і натисни «Хлопчик» або «Дівчинка».
3. Скопіюй три рядки, що з'являться, і встав їх у `content.js`, у блок `lock`.
4. Закоміть і передеплой.

Кнопка «Пройти самому спочатку» на тій же панелі скидає «замок уже
відчинено» на цьому телефоні — щоб прогнати весь сценарій з нуля.

Для швидкої перевірки без коду є чорний хід `?s=south` (або `?s=north`):
пропускає заставку й замок. Параметр стирається з адреси одразу, у консоль
не потрапляє. **Паре це посилання не давати.**

## Посилання в месенджері

`index.html` містить og-теги: коли посилання кидають у Telegram чи iMessage,
воно розгортається карткою — латунне коло, «Лабіринт для двох», «Пройдіть його
разом, на одному телефоні». Ані коду, ані статі там немає. Картинка —
`assets/img/og.jpg` (1200×630), іконка на домашній екран — `assets/img/icon-180.png`.

⚠ Адреса картинки в `og:image` **абсолютна** і зашита на
`https://labirynt-production.up.railway.app`. Зміниться домен — поміняти й там,
інакше прев'ю зникне.

## Деплой на Railway

**Живе тут: https://labirynt-production.up.railway.app**
Окремий проєкт Railway `labirynt-dvoje` (id `cb914357-ff2c-473f-bd17-87a6de1e87e7`),
служба `labirynt`. З симулятором BSO не має нічого спільного — окремий проєкт,
не окрема служба в проєкті BSO.

⚠ **`railway up` бере корінь git-репозиторію, а не теку, з якої запускаєш.**
Запуск із `labirynt/` заллє весь `brain-spine-orchestrator` і служба підніме
симулятор замість лабіринту (напоролись 09.09). Тому заливати треба з копії
поза репозиторієм:

```bash
rm -rf /tmp/lab && mkdir /tmp/lab
cd labirynt && tar cf - . | (cd /tmp/lab && tar xf -)
cd /tmp/lab
railway up --service labirynt \
  --project cb914357-ff2c-473f-bd17-87a6de1e87e7 \
  --environment production --detach -y
```

Щоб позбутися цього кроку назавжди — підключити службу до GitHub-репо і
виставити Settings → **Root Directory: `labirynt`**; тоді Railway підхоплюватиме
кожен push сам.

Сервер — `server.py` на stdlib, без залежностей: віддає статику, ассети з
довгим кешем, код без кешу, будь-який невідомий шлях — назад на `index.html`.
У логи не пише ні шляхів, ні кодів.

Альтернатива — GitHub Pages: скопіювати вміст цієї теки в корінь окремого
приватного репо (Pages не публікує довільну підпапку, крім `/docs`).

## Інструкція Ігорю (5 рядків)

1. **Тексти заставки** — `content.js`, блок `prologue`: сім сторінок, у кожній масив рядків. `tone: 'a'` — кольори Саші, `'b'` — Софії.
2. **Запитання лабіринту** — там же, блок `questions`: по черзі Саша/Софія, у кожної відповіді є `trait` для «портрета батьків».
3. **Фото** — кинути `01.jpg, 02.jpg …` у `assets/photos/` і додати ті ж імена у список `photos.items`.
4. **Музика** — покласти `prologue.mp3`, `walk.mp3`, `reveal.mp3`, `memories.mp3`
   у `assets/audio/` (саме такі назви).
5. **Передеплой** — `git add -A && git commit -m "..." && git push`; Railway підхопить сам.

## Локальний запуск

```bash
cd labirynt
python3 server.py          # → http://localhost:8000
```

Відкривати через `file://` не можна — не завантажиться `content.js`.

## Стан робіт

**Живе на https://labirynt-production.up.railway.app — готове до відправки пари.**

Готово й перевірено живим проходом у WebKit по продакшн-адресі: екран
«хто відкрив», розділена заставка, замок із пін-кодом, лабіринт, вердикт,
reveal, фінальна картка, три треки, свайп, og-прев'ю посилання, верстка на
чотирьох айфонах від 320×568 до 430×932.

Музика (усі три — файли Ігоря, перекодовані в 160 kbps):

| Файл | Трек | Де грає |
|---|---|---|
| `prologue.mp3` | Ólafur Arnalds — Saman, 2:12 | заставка й замок, з дотику по кнопці вибору |
| `walk.mp3` | Bear's Den — Sophie (live at Vondelkerk), 5:05 | увесь лабіринт |

Між ходою і фіналом — рівно секунда темряви й тиші. Не скорочувати.

Рішення власника, які закривають питання:

- **Фотографій не буде.** Список `photos.items` порожній, екран не показується,
  кнопка після reveal каже «Далі», а не «Ваша дорога сюди». `memories.mp3`
  більше не потрібен.
- **Заставка розділена.** Софія читає звертання до мами, Саша — до тата,
  чужого не бачить жоден. Спільні сторінки — обом.
- **Тексти 14 запитань лишаються ті, що є** (їх писав Claude). Прототипу
  `labirynt.html` не існує ні в репозиторії, ні в історії git; артефакт, що
  Ігор прислав 09.09, виявився знімком цієї ж роботи — тексти в ньому
  посимвольно ті самі.
