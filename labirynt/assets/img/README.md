# assets/img/

Растрові елементи, якщо Ігор намалює свої (текстури, рамки, іконки).

Зараз **усе робиться в SVG/CSS** і ця папка порожня — вона потрібна тільки
якщо з'явиться намальована графіка. Файли звідси нікуди автоматично не
підтягуються: їх треба явно підключити в `style.css` або `index.html`.
