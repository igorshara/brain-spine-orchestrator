# assets/audio/

Клади сюди три файли **саме з такими назвами** (mp3, моно або стерео, до ~4 МБ кожен):

| Файл | Де звучить | Який має бути |
|---|---|---|
| `walk.mp3` | фон під час проходження лабіринту | тихий, зациклений (безшовна петля), без різких піків |
| `reveal.mp3` | стартує рівно в момент спалаху | має яскравий вступ із перших секунд |
| `memories.mp3` | під фотографіями | спокійний, зациклений |

Якщо треку немає — застосунок просто працює без нього, нічого не ламається.
`memories.mp3` може бути копією `reveal.mp3`, якщо трек один.

**Ліцензії:** тільки безкоштовні / CC-ліцензійні джерела.
