# assets/photos/

Фото пари для екрана «Ваша дорога сюди».

1. Назви файли `01.jpg`, `02.jpg`, `03.jpg` … — порядок показу = порядок номерів.
2. Стисни до **1600 px по довгій стороні** (загальна вага сторінки — до 25 МБ).
3. Пропорція кадру на екрані — 3:4 (вертикальна). Горизонтальні фото обріжуться по центру.
4. **Обов'язково** додай кожен файл у список `photos.items` у `content.js`:

```js
photos: {
  title: 'Ваша дорога сюди',
  items: [
    { file: '01.jpg', caption: '' },
    { file: '02.jpg', caption: 'Той самий вечір' }
  ]
}
```

`caption` необов'язковий — можна лишити порожнім.
Якщо список порожній, екран із фото просто пропускається.
